# `domain`

Global, platform-independent domain code shared across features.

Reserved for Phase 3+: shared entities, value objects and abstract contracts.
Nothing is implemented yet by design — Phase 1 only establishes the package so
business logic can be reused unchanged by future Android/iOS clients.

## Planned contents (not implemented)
